ANGWY is an adversarial rigor protocol for AI agents. It converts high-pressure input into rigorously verified output through an internal audit loop: draft, adversarial attack, repair, and compression. It is always-on by default, treats every input as high-standard, and enforces anti-sycophancy, forced verification, and loss-aware framing. Compatible with OpenCode, Claude Code, Cursor, Codex, and any agent that supports the Agent Skills specification.
